# Sell By End Of Week Plan

## Day 1: Supabase And Hosting

- Create a new Supabase project.
- Run the SQL migration.
- Configure `config.js`.
- Deploy the static app to Netlify/Vercel/Cloudflare Pages.
- Create a test user and confirm data saves.

## Day 2: Website And Checkout

- Add a product page to `scaleuptech.org`.
- Use screenshots from the deployed app.
- Create a Stripe Payment Link.
- Add the Stripe link to `config.js`.
- Publish pricing, refund terms, privacy policy, and responsible-use note.

## Day 3: Support Readiness

- Create `support@scaleuptech.org`.
- Prepare replies for login, payment, refund, and "how do I use it?" questions.
- Record a 2-3 minute walkthrough video.
- Create a demo account for prospects.

## Day 4: Paid Beta

- Sell as a paid beta or early-access product.
- Keep expectations clear: cloud workspace now, desktop automation bundle optional.
- Manually upgrade customer plans in Supabase until Stripe webhooks are added.

## Day 5: Automation Upgrade

- Add Stripe webhook to update `subscriptions`.
- Add AI scoring Edge Function.
- Add CSV export and weekly email report if customers request it.

## Important Sales Wording

Use:

- "Job search workspace"
- "Application tracker"
- "AI fit scoring"
- "Saved searches"
- "Pipeline analytics"
- "Desktop assistant bundle"

Avoid:

- "Guaranteed interviews"
- "Guaranteed job offers"
- "Unlimited auto apply"
- "Bypasses job board limits"
- "Cloud scraping of LinkedIn"
